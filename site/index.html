India Tech News Agent

Automated briefing pipeline: Indian sources, neural voice, captioned video, and multi-channel publish.

What it does

  • Ingest — Google News RSS (India search + India top stories) with optional article text extraction.
  • Script — Local LLM via Ollama (structured JSON bulletin).
  • Voice — Microsoft Edge neural voices (Indian English / Hindi fallbacks) or macOS say.
  • Video — FFmpeg: gradient studio, reporter image or clip, waveform, timed captions (720p for Telegram).
  • Publish — Telegram, YouTube, or local files.

Deploy note

This site is a static project overview for Vercel. The Python worker (Ollama, FFmpeg, long jobs, Telegram long-poll) runs on your own machine, VPS, or CI — not inside Vercel serverless limits.

See the repository README for setup, environment variables, and scheduling.
